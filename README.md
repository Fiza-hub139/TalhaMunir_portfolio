## 🚀 Key Highlights & Features

* **High Performance & Responsive UI:** Built with Tailwind CSS, supporting seamless dark/light theme switching.
* **SEO Optimized:** Full Open Graph (OG) tags, Twitter cards, meta titles, descriptions, and semantic HTML5 tag hierarchy.
* **Structured Data Markup:** Schema.org (JSON-LD & Microdata) integration for `Person`, `ContactPoint`, and `CreativeWork` entities for Google Rich Search Results.
* **3D Visual Experience:** WebGL/Three.js integrated background canvas for a modern developer aesthetic.
* **Accessibility (a11y) First:** Screen-reader ready with ARIA labels, semantic landmark tags, and keyboard navigation support.
